# AI SIGNAL Research Desk — 기획서

작성: 2026-10-13. 대상: DevOps·Solution Architect의 기술 학습과 개인 페이지 관리.

## 제품 방향

뉴스 수집을 읽고 끝내지 않고, 기사 묶음 → 내 해석 → 작은 실습 → 브리핑 페이지로 연결한다. 기존 AI SIGNAL은 발견의 공간, Research Desk는 정리와 실행의 공간이다. 유료 AI 호출 없이 시작한다.

## 1차 기능

- 로그인: Keycloak 로컬 계정과 선택적으로 Google·네이버 OIDC 로그인.
- 최근 AI SIGNAL 기사 12건을 조회하고 선택한 기사 제목·원문 링크를 브리핑에 담기.
- 페이지 작성·수정, 메모, 최대 12개 태그, 최대 30개 근거 링크.
- 학습 단계: 읽기 / 실습 / 정리. 단계별 보유 페이지 건수를 상단 표시.
- 초안은 작성자·관리자에게만 표시. 공유 페이지는 앱 역할을 가진 사용자에게 표시. 인터넷 공개 게시 기능은 아니다.
- 제목·태그·본문 검색: 현재 가져온 최근 100개 페이지 안에서 검색한다.
- editor는 자기 페이지 작성·수정, admin은 전체 수정·삭제, viewer는 공유 페이지 열람.
- 동시 수정은 version으로 감지한다. 충돌 시 강제 덮어쓰지 않는다.

## 재미를 더할 후속 기능 제안

1. **주간 아키텍처 브리핑**: 한 주의 기사 3개와 내 의견을 템플릿으로 정리. 현재는 직접 작성, 예약·자동 발행은 후속.
2. **실습 퀘스트**: 기사마다 ‘Terraform 모듈 만들기’, ‘장애 재현하기’ 같은 체크리스트와 회고. 현재 본문에 텍스트로 작성 가능하며 체크박스 상태 자동 집계는 후속.
3. **아키텍처 결정 노트(ADR)**: 대안·비용·운영 영향 비교를 페이지 유형으로 확장.
4. **개인 역량 지도**: IAM/Kubernetes/SRE/IaC 태그별 학습량과 최근 실습 기록. 현재 단계별 건수만 구현.
5. **선택적 Obsidian/Notion 내보내기**: 기존 knowledge-notes와 연계. 이번 앱에는 자동 동기화나 Notion API를 연결하지 않는다.

## 완료 기준과 제외

로컬 빌드 및 권한 테스트, Terraform validate/mock plan, 문서와 IaC PR을 제공한다. 실제 AWS apply·Cloudflare 배포·소셜 제공자 검수는 사용자가 수행한다. 자동 AI 요약, 파일 업로드, 복잡한 WYSIWYG, 조직별 멀티테넌시, 즉시 SSO 세션 철회, 이력 복구 UI는 이번 범위 밖이다.
